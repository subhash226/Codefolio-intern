# Proofline Resume Builder

- Added a changelog file so repository updates are easier to track.

## Run locally

Copy `.env.example` to `.env`, set a strong `JWT_SECRET`, and configure SMTP if you want password reset codes sent by email. Then run the client and API in separate terminals:

```powershell
npm run dev
npm run server:dev
```

The API runs at `http://localhost:4000`. It persists development data to `DATA/resume-builder.json` and profile images to `server/uploads/`.

If SMTP is configured with `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, and optionally `SMTP_FROM`, password reset codes will be delivered by email instead of only returned in development mode.

## API

Protected endpoints require `Authorization: Bearer <token>`.

- `POST /api/auth/register`, `POST /api/auth/login`, `POST /api/auth/logout`
- `POST /api/auth/forgot-password`, `POST /api/auth/reset-password`
- `GET/PATCH /api/profile`, `POST /api/profile/photo`
- `GET/POST /api/resumes`, `GET/PUT/DELETE /api/resumes/:id`
- `POST /api/resumes/:id/duplicate`
- `GET /api/resumes/:id/versions`
- `POST /api/resumes/:id/versions/:versionId/restore`

Resume payloads include personal information, education, experience, categorized/proficiency-rated skills, projects, certifications, template selection, and color/font/layout customization. Every update stores a version snapshot for restore.
